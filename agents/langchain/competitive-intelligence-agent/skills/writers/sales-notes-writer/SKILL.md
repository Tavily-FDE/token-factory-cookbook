# Sales Notes Writer

Sales notes should be practical, short, and safe to use in customer-facing
conversations.

## Workflow

1. Identify the seller role and deal stage.
2. Select verified copy-safe facts that help the seller frame the conversation.
3. Separate customer-facing language from internal notes.
4. Use bullets, short talk tracks, and crisp caveats.
5. Include avoided claims when a useful angle lacks verified support.

## Suggested Structure

```markdown
# Sales Notes: <Scope>

## Context

## Safe Talk Tracks

## Discovery Prompts

## Proof Points

## Internal Cautions
```

## Gotchas

- Do not overload sellers with long prose.
- Do not include uncertain claims unless clearly marked internal.
- Do not remove competitor strengths that affect qualification.
